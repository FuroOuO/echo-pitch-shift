# EchoMusic 歌曲变调助手插件 (Echo Pitch Shift)

> 专为 [EchoMusic](https://github.com/hoowhoami/EchoMusic) 打造的实时歌曲升调、降调插件。  
> 采用方案 A（音源拦截 + 本地流式转码代理），无需修改或重新编译播放器客户端即可直接使用。

- **作者**：FuroOuO  
- **当前版本**：1.0.0  
- **适配客户端**：EchoMusic >= 2.2.0  

---

## 一、 功能特性

* 🎵 **平滑变调**：支持 $\pm 6$ 个半音（Semitones）的升降调微调；
* ⚡ **变调不变速**：基于 `asetrate` 与 `atempo` 补偿算法，严格保持原曲节拍速度不变；
* 🎛️ **独立悬浮调节面板**：
  * 精准显示当前曲目、升降半音数及实时频响倍率；
  * 提供 `♭ 降调`、`♯ 升调`、`原调` 快捷按键；
  * 提供 `-3 ~ +3` 常用半音快速切换标签；
  * 优雅的磨砂玻璃悬浮窗风格，支持自由拖拽；
* 📌 **播放栏无缝集成**：在播放栏右侧实时展示当前调号 Badge（如 `原调`、`+1`、`-2`），点击即刻呼出/隐藏调节面板；
* 🛡️ **智能生命周期**：切歌或关闭时自动释放转码子进程与代理连接，不占系统闲置资源。

---

## 二、 安装与使用方式

### 步骤 1：将插件导入 EchoMusic
1. 打开 **EchoMusic** 客户端；
2. 点击左下角 **设置** → **插件管理** → **打开插件目录**；
3. 将本项目文件夹 `echo-pitch-shift` 复制到该目录下。

### 步骤 2：启用插件与授权
1. 在 EchoMusic 插件管理列表中找到 **歌曲变调助手**，开启右侧开关；
2. 首次启动时，主程序会弹窗提示请求“本地辅助进程 (process)”权限，点击 **允许**。

### 步骤 3：调节歌曲音调
1. 播放任意歌曲；
2. 在底部播放控制栏右侧会看到 **“歌曲升降调”** 图标与调号徽标；
3. 点击图标呼出调节面板，点击 `♭` 降调或 `♯` 升调，歌曲将即时应用新调号播放！

## 三、 核心算法原理

本插件基于音频声学与乐理中的 **十二平均律（12-TET）**，采用 FFmpeg 原生内置滤镜构建的高性能“变调不变速”复合算法。无需依赖体积庞大的第三方外部音频扩展库（如 SoundTouch 或 Rubberband），即可实现低延迟、低资源占用的实时音频变调。

### 1. 变调倍率计算（十二平均律）
根据十二平均律，一个八度（Octave）的频率翻倍（$2\times$），并被等比均分为 12 个半音（Semitone）。  
若目标变调半音偏移量为 $N \in [-6, +6]$，则对应音频频率（音高）缩放倍率 $R$ 为：

$$R = 2^{\frac{N}{12}}$$

* **升调（$N > 0$）**：$R > 1$，如升 1 个半音时 $R = 2^{1/12} \approx 1.059463$；
* **降调（$N < 0$）**：$R < 1$，如降 1 个半音时 $R = 2^{-1/12} \approx 0.943874$；
* **原调（$N = 0$）**：$R = 1$。

### 2. 两步复合滤镜：变调不变速
常规直接调整播放速率会导致“变调且变速”（类似留声机或黑胶唱盘加速）。为了实现**改变歌曲音调但原曲节拍速度（BPM）严格保持不变**，插件将变调与速度补偿解耦为两步级联处理：

```
原始音频流 (44.1kHz, 1.0x 原始速度)
          │
          ▼
┌────────────────────────────────────────────────────────┐
│ 步骤 1：asetrate = 44100 × R                            │
│ 修改标称采样率，改变采样点重放频率                      │
│ 【效果】：音调变为 R 倍（实现升/降调），但播放速度也变为 R 倍│
└────────────────────────────────────────────────────────┘
          │
          ▼
┌────────────────────────────────────────────────────────┐
│ 步骤 2：atempo = 1 / R                                  │
│ 基于时域波形相似叠加算法（WSOLA）反向补偿时间轴         │
│ 【效果】：保持当前变调后的音调不变，将速度精准拉回 1.0x 原速 │
└────────────────────────────────────────────────────────┘
          │
          ▼
输出实时转码音频流 (目标新音调, 严格保持原曲 1.0x BPM 节奏)
```

1. **第一步（重设采样率变调）：`asetrate`**  
   在不重新计算插值的情况下，直接修改音频流标称采样率 $F_s' = 44100 \times R$。解码器按新采样率读取时，声音频率被整体缩放 $R$ 倍（音调升高或降低），但此时单位时间内读取的音频数据量也变为 $R$ 倍，导致播放速率同步变为 $R$ 倍。
2. **第二步（速度反向补偿）：`atempo`**  
   级联 FFmpeg 原生 `atempo` 滤镜，传入速度补偿系数 $T = \frac{1}{R}$。该滤镜采用基于波形相似重叠（WSOLA）的声学时域拉伸算法，在**保持现有音高不变的前提下**反向缩放播放速度（$R \times \frac{1}{R} = 1.0$），从而抵消第一步带来的速度改变，达成完美的“变调不变速”。

### 3. 动态滤镜参数示例
在插件底层（[`index.js`](./index.js)），根据当前半音数动态计算并注入 FFmpeg 管道：

| 半音偏移 $N$ | 变调说明 | 频率缩放比 $R$ | 重设采样率 (`asetrate`) | 速度补偿系数 (`atempo`) | 最终生效滤镜参数 (`-af`) |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **+2** | 升 2 个半音 | $\approx 1.122462$ | `49501` | `0.890899` | `-af "asetrate=49501,atempo=0.890899"` |
| **+1** | 升 1 个半音 | $\approx 1.059463$ | `46722` | `0.943874` | `-af "asetrate=46722,atempo=0.943874"` |
| **-1** | 降 1 个半音 | $\approx 0.943874$ | `41625` | `1.059463` | `-af "asetrate=41625,atempo=1.059463"` |
| **-2** | 降 2 个半音 | $\approx 0.890899$ | `39289` | `1.122462` | `-af "asetrate=39289,atempo=1.122462"` |

### 4. 方案优势
* **免除复杂依赖**：完全依赖 FFmpeg 内置的原生滤镜，无需额外安装或编译复杂的 C++ 音频库；
* **极低资源开销**：转码与速度补偿算法计算量小，CPU 占用低，播放流畅无卡顿；
* **音质自然平滑**：在 $\pm 6$ 个半音范围内，人声与乐器音色过渡平滑，无明显相位撕裂失真。
